================================================================================
TROUBLESHOOTING
================================================================================

Se ainda receber erro "ModuleNotFoundError":
  1. Verifique se o redeploy foi concluido
  2. Limpe cache do navegador (Ctrl+Shift+Del)
  3. Aguarde mais alguns minutos
  4. Atualize a pagina

Se receber erro "FileNotFoundError" para Excel:
  1. Verifique se fornecedores_nibo.xlsx esta no repositorio
  2. Confirme o path em main.py

Se a pagina ficar branca/travada:
  1. Atualize a pagina (F5)
  2. Verifique o console do navegador (F12)
  3. Acesse Streamlit Cloud > app > "Manage app" > View logs
